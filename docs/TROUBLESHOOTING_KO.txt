AIR WRITING 시연 문제해결 안내서
작성일: 2026-09-16

문제가 발생하면 아래에서 증상과 같은 항목을 찾고 위에서 아래 순서대로 처리합니다.
한 번에 여러 설정을 바꾸지 마세요. 한 단계씩 확인해야 원인을 구분할 수 있습니다.


============================================================
1. Python 창이 실행하자마자 닫힘
============================================================

원인:
- .py 파일을 더블클릭해서 실제 오류를 볼 수 없는 경우
- Python 또는 필수 패키지가 없는 경우

해결:
PowerShell을 열고 반드시 다음 명령으로 실행합니다.

cd "C:\Users\Demo\Desktop\파이썬 실행!"
py unity_ai_bridge_purebilstm_bestperformance.py

화면에 나오는 마지막 오류 문장을 사진으로 남깁니다.


============================================================
2. 'py' 또는 'python'을 찾을 수 없다고 나옴
============================================================

원인:
- Demo 사용자에 Python이 설치되지 않았거나 실행 경로가 등록되지 않음

해결:
- Python 3.12 64-bit를 설치합니다.
- 설치할 때 Add Python to PATH 또는 Python Launcher 항목을 선택합니다.
- PowerShell을 완전히 닫고 새로 엽니다.
- py --version을 실행합니다.


============================================================
3. No module named 'numpy', 'torch', 'serial', 'sklearn' 등이 나옴
============================================================

원인:
- 현재 Demo 사용자 Python에 필수 패키지가 설치되지 않음
- pyserial 하나만 설치하고 나머지를 설치하지 않은 경우

해결:

cd "C:\Users\Demo\Desktop\파이썬 실행!"
py -m pip install -r requirements.txt

설치 확인:

py -c "import numpy, torch, sklearn, serial, scipy; print('AI PACKAGE OK')"


============================================================
4. main.py를 찾을 수 없다고 나옴
============================================================

현재 시연은 main.py를 실행하지 않습니다.
다음 Bridge 파일을 실행해야 합니다.

py unity_ai_bridge_purebilstm_bestperformance.py


============================================================
5. 사용할 수 있는 COM 포트가 없다고 나옴
============================================================

확인 순서:
1) 장갑 전원이 켜졌는지 확인
2) USB 케이블을 뽑았다가 다시 연결
3) 데이터 전송이 가능한 USB 케이블인지 확인
4) Windows 장치 관리자에서 포트(COM 및 LPT) 확인
5) 다른 USB 포트에 연결
6) 장갑을 연결한 뒤 Bridge를 다시 실행

충전 전용 USB 케이블은 전원만 들어오고 COM 포트가 생기지 않습니다.


============================================================
6. COM 포트 접근 거부 또는 포트를 열 수 없다고 나옴
============================================================

원인:
- Arduino Serial Monitor, main.py 또는 다른 Bridge가 같은 장갑을 사용 중

해결:
- Arduino IDE의 Serial Monitor 종료
- 다른 PowerShell의 Bridge 종료
- main.py 웹 서버 종료
- Unity는 그대로 두어도 되지만 Python Bridge는 반드시 하나만 실행
- 해결되지 않으면 장갑 USB 재연결 후 Windows 재부팅


============================================================
7. S3 손가락 IMU 끊김 또는 accel=0, gyro=0
============================================================

원인:
- S3 센서 케이블 또는 커넥터 접촉 불량
- 장갑 펌웨어에서 S3 값이 0으로 전송됨

해결:
1) Bridge와 Unity 종료
2) 장갑 전원 끄기
3) S3 커넥터를 단단히 다시 연결
4) 장갑 전원 및 USB 다시 연결
5) Bridge 재실행

S3가 실제로 0이면 소프트웨어만으로 복구할 수 없습니다.


============================================================
8. 캘리브레이션 후 포인터가 빠르게 위·아래 또는 끝으로 이동함
============================================================

주요 원인:
- 초기 캘리브레이션 중 장갑을 움직임
- 장갑을 책상에 둔 자세와 실제 착용 자세가 크게 다름
- 센서 초기화 순간에 충격이 들어감

해결:
1) K를 누릅니다.
2) 실제로 글씨를 쓸 때와 비슷한 정면 자세로 장갑을 듭니다.
3) 4~6초 동안 손과 손가락을 완전히 고정합니다.
4) TRACKING 안내가 나온 다음 움직입니다.
5) 중심만 어긋났다면 K 대신 R을 누릅니다.

R은 중앙만 맞추고, K는 센서 보정부터 다시 시작합니다.


============================================================
9. Unity에서 CONNECTION이 연결되지 않음
============================================================

확인 순서:
1) Python Bridge 터미널에 Unity 100 Hz가 출력되는지 확인
2) Python Bridge를 먼저 실행했는지 확인
3) 다른 Bridge가 동시에 실행 중인지 확인
4) UDP 포트 12346을 사용하는 다른 프로그램 종료
5) Windows 방화벽 알림이 나오면 로컬/개인 네트워크 허용
6) Unity와 Bridge를 모두 종료한 뒤 Bridge → Unity 순서로 재실행

이 구성은 같은 노트북 내부의 127.0.0.1:12346을 사용하므로
인터넷 연결이 없어도 작동합니다.


============================================================
10. 포인터는 움직이지만 선이 그려지지 않음
============================================================

확인:
- Unity INPUT RAW 값이 0에서 1로 변하는지 확인
- 압력 센서를 눌렀을 때 Python의 Pen UP/DOWN 또는 writing 값 확인

해결:
- 압력 센서 위치를 정확히 누릅니다.
- 장갑 펌웨어가 writing 신호를 전송하는지 확인합니다.
- S3/FSR 커넥터를 다시 연결합니다.
- 다른 Bridge나 Serial Monitor를 종료하고 다시 실행합니다.


============================================================
11. Python에는 AI 결과가 나오지만 Unity Recognition Result는 비어 있음
============================================================

원인 후보:
- 호환되지 않는 streaming.py 사용
- 이전 Bridge가 함께 실행 중
- Unity UDP 수신 상태가 끊김

현재 Demo 폴더에는 정상 검증된 호환용 streaming.py가 들어 있습니다.
이를 다른 폴더의 파일로 교체하지 마세요.

복구 순서:
1) Unity와 모든 Bridge 종료
2) 현재 Demo 폴더의 Bridge 하나만 실행
3) TRACKING 확인
4) Unity 실행
5) A를 쓰고 약 1초 기다림


============================================================
12. 글자가 연속해서 두 번 인식됨
============================================================

원인 후보:
- 다른 Bridge 두 개가 동시에 실행 중
- 한 글자 작성 중 압력 신호가 여러 번 끊김
- 글자 사이의 멈춤 시간이 너무 길거나 불규칙함

해결:
- Python 창이 하나만 열려 있는지 확인합니다.
- 획 사이를 빠르고 자연스럽게 연결합니다.
- 글자 하나가 끝나면 손을 떼고 약 1초 기다립니다.
- FSR와 S3 연결 상태를 확인합니다.


============================================================
13. 특정 글자를 계속 다른 글자로 인식함
============================================================

현재 모델은 저장 데이터 평가에서는 매우 높은 정확도를 보였지만,
실시간 장갑 필기는 작성 자세와 센서 편차에 따라 오인식될 수 있습니다.

작성 요령:
- 글자를 너무 작거나 지나치게 크게 쓰지 않기
- 획 순서를 일정하게 유지하기
- F/E, D/P처럼 비슷한 글자는 구별되는 획을 분명하게 쓰기
- 획 사이에서 압력이 불필요하게 끊기지 않게 하기
- 한 글자가 확정된 후 다음 글자 쓰기

현재 장갑은 S2 MAPPED + Y 반전 설정을 기본으로 사용합니다.
이 장갑에서 잘되는 설정이므로 시연 직전에 옵션을 바꾸지 마세요.


============================================================
14. 글씨 방향이 위아래로 반대임
============================================================

현재 기본값은 Y 반전입니다. 현재 장갑의 센서 방향에 맞춘 설정입니다.
반전이 필요 없는 다른 장갑에서만 다음 옵션을 사용할 수 있습니다.

py unity_ai_bridge_purebilstm_bestperformance.py --ai-normal-y

현재 시연 장갑에서는 기본 실행 명령을 그대로 사용하세요.


============================================================
15. 포인터/필기는 되지만 인식률이 갑자기 낮아짐
============================================================

복구 순서:
1) K로 전체 재보정
2) S2/S3/FSR 커넥터 확인
3) 다른 Bridge와 Serial Monitor 종료
4) Bridge 재실행 후 모델명이 pure_bilstm인지 확인
5) weights\pure_bilstm.pt와 weights\meta.pkl을 바꾸지 않았는지 확인
6) A, B, C를 한 글자씩 시험

시연 도중 모델 재학습이나 패키지 업데이트는 하지 않습니다.


============================================================
16. scikit-learn 버전 경고가 표시됨
============================================================

InconsistentVersionWarning만 표시되고 모델 로드 완료가 이어서 나온다면
즉시 종료되는 치명적 오류는 아닙니다.

현재 meta.pkl은 scikit-learn 1.8.0 환경을 권장합니다.
시연 직전에 경고를 없애려고 무리하게 패키지를 변경하지 마세요.
모델 로드 실패가 실제로 발생했을 때만 환경을 조정합니다.


============================================================
17. Unity 버튼이 눌리지 않거나 시작 화면 입력이 이상함
============================================================

- Unity 창을 마우스로 한 번 클릭해 포커스를 줍니다.
- Start Demo 버튼은 마우스 또는 장갑 입력으로 누릅니다.
- 메인 화면으로 넘어온 직후 남은 입력이 보이면 손을 떼고 약 1초 기다린 뒤 Clear를 누릅니다.
- 문제가 반복되면 Unity와 Bridge를 모두 재실행합니다.
