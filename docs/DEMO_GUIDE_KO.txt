============================================================
1. 현재 시연 구성
============================================================

[Unity 실행 폴더]
C:\Users\Demo\Desktop\유니티! AirWriting_Unity_Hybrid_Demo

[Unity 실행 파일]
C:\Users\Demo\Desktop\유니티! AirWriting_Unity_Hybrid_Demo\AirWriting_Unity.exe

[Python AI 폴더]
C:\Users\Demo\Desktop\파이썬 실행!

[실행할 Bridge]
unity_ai_bridge_purebilstm_bestperformance.py

[실제로 불러오는 AI 모델]
weights\pure_bilstm.pt
weights\meta.pkl

이 Bridge는 Pure BiLSTM 단일 글자 인식 모델을 사용합니다.
Bridge 파일 자체가 학습 모델은 아닙니다. 학습 결과는 weights 폴더의
pure_bilstm.pt와 meta.pkl 한 쌍에 저장되어 있습니다.

현재 Demo 바탕화면의 Bridge, 모델, meta.pkl, streaming.py는
기존에 정상 작동을 확인한 최종 검증본과 파일 내용이 동일합니다.

기본 AI 입력 설정:
- S2 MAPPED
- Y축 반전
- 글자 확정 대기: 0.8초
- 띄어쓰기 대기: 2.0초
- Unity UDP 포트: 12346


============================================================
2. 최초 1회만 준비할 것
============================================================

Demo 사용자 계정에서 PowerShell을 열고 아래 명령을 차례대로 실행합니다.

cd "C:\Users\Demo\Desktop\파이썬 실행!"
py --version
py -m pip install -r requirements.txt

Python 버전은 3.12.x를 권장합니다.
패키지 설치는 처음 한 번만 하면 됩니다. torch 설치는 시간이 걸릴 수 있습니다.

설치 확인 명령:

py -c "import numpy, torch, sklearn, serial, scipy; print('AI PACKAGE OK')"

마지막에 AI PACKAGE OK가 나오면 준비가 끝난 것입니다.


============================================================
3. 시연 당일 실행 순서
============================================================

1) 노트북 전원을 연결합니다.

2) Windows의 Demo 사용자로 로그인합니다.

3) 장갑의 전원과 USB 연결을 확인합니다.
   장치 연결 후 3~5초 기다립니다.

4) 다음 프로그램이 열려 있다면 모두 종료합니다.
   - Arduino Serial Monitor
   - main.py 웹 서버
   - 다른 unity_bridge 파일
   - 장갑 COM 포트를 사용하는 다른 프로그램

5) PowerShell을 엽니다.

6) 아래 명령으로 Python 폴더로 이동합니다.

cd "C:\Users\Demo\Desktop\파이썬 실행!"

7) 아래 명령으로 AI Bridge를 실행합니다.

py unity_ai_bridge_purebilstm_bestperformance.py

8) 캘리브레이션 안내가 나오면 장갑을 정면의 편한 자세로 잡고
   4~6초 동안 최대한 움직이지 않습니다.

9) 터미널에 다음 내용이 표시될 때까지 기다립니다.
   - 모델 로드 완료: pure_bilstm
   - 연결 성공: ESP32 Serial
   - 자이로 보정 완료
   - 포인터 기준점 설정 완료
   - 상태: TRACKING

10) TRACKING이 나온 뒤 다음 파일을 실행합니다.

C:\Users\Demo\Desktop\유니티! AirWriting_Unity_Hybrid_Demo\AirWriting_Unity.exe

11) Unity에서 Start Demo를 누르고 메인 화면으로 이동합니다.

12) 포인터가 중앙에 맞지 않으면 Unity 화면을 한 번 클릭한 뒤 R을 누릅니다.

13) 글자를 한 글자씩 또렷하게 씁니다.
   - 획 사이에는 너무 오래 멈추지 않습니다.
   - 글자 하나가 끝난 뒤 약 1초 기다립니다.
   - 결과가 확정된 다음 다음 글자를 씁니다.


============================================================
4. 사용 키
============================================================

R : 빠른 중앙 재설정
    포인터 중심만 다시 맞춥니다. 필터 전체를 다시 보정하지 않습니다.

K : 전체 캘리브레이션 재시작
    포인터가 저절로 크게 움직이거나 한쪽 끝으로 수렴할 때 사용합니다.
    K를 누른 뒤 장갑을 정면 자세로 4~6초간 완전히 가만히 둡니다.

D : 상세 로그 켜기/끄기
    문제가 생겼을 때 센서와 전송 상태를 자세히 확인합니다.

Q : Python AI Bridge 안전 종료

FSR 3초 이상 길게 누르기:
    지원되는 펌웨어에서는 포인터 중앙을 다시 설정하고 작성 중인 획을 정리합니다.
    장갑 펌웨어가 장압 신호를 보내지 않으면 이 기능은 작동하지 않을 수 있습니다.


============================================================
5. 정상 작동 표시
============================================================

Python 터미널:
- model=pure_bilstm
- Sensors OK
- Unity 100 Hz
- cksum_err=0
- drop=0 또는 매우 작은 값
- AI 결과와 신뢰도 출력

Unity 화면:
- CONNECTION: CONNECTED
- TRACKING: TRACKING
- 포인터가 장갑 움직임을 따라감
- 필기 종료 후 RECOGNITION RESULT에 글자가 나타남


============================================================
6. 종료 순서
============================================================

1) Unity를 종료합니다.
2) Python 터미널을 선택하고 Q를 누릅니다.
3) 종료 메시지가 나온 뒤 장갑 USB와 전원을 분리합니다.

강제로 PowerShell 창을 닫아도 되지만, 가능하면 Q로 먼저 종료합니다.


============================================================
7. 절대로 바꾸거나 분리하지 말 것
============================================================

- 파이썬 실행! 폴더 안의 Bridge만 단독으로 다른 곳에 옮기지 않습니다.
- weights\pure_bilstm.pt와 weights\meta.pkl은 반드시 같은 학습 결과 한 쌍이어야 합니다.
- airwriting_imu\core\streaming.py를 다른 버전으로 교체하지 않습니다.
- Unity EXE만 단독으로 옮기지 않습니다. 전체 Unity 폴더를 함께 옮겨야 합니다.
- 시연 직전에 모델 재학습, 패키지 업그레이드, 코드 수정은 하지 않습니다.
- 정상 동작을 확인한 현재 두 폴더는 그대로 보존합니다.
