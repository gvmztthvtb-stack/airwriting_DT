# Windows demo build

The Windows Unity build is distributed as a GitHub Release asset instead of being committed to Git history.

The release ZIP must contain the complete Unity build directory, including `AirWriting_Unity.exe`, `AirWriting_Unity_Data/`, `MonoBleedingEdge/`, `D3D12/`, and the Unity runtime DLLs. The `AirWriting_Unity_BurstDebugInformation_DoNotShip/` directory is excluded.

Prepared asset:

- File: `AirWriting_Unity_Hybrid_Demo_v1.0.1.zip`
- Size: 36.86 MiB
- SHA-256: `4D8DB2A4507F285D5FD15D38C8058DA40E18151FCFC6B0952A3A2F10D3ABE291`

Version 1.0.1 uses the final presentation build with the F2 settings panel, F3 presenter view, and automatic Display 2 output. Version 1.0.0 used the earlier digital-twin build and did not include these presentation controls.
